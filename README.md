# Academic Research Skill Codex

This repository is a structured research-support system for PhD application preparation, academic paper reading, supervisor matching, research proposal development, motivation letter drafting, and academic writing refinement.

It is designed for research interests around industrial design, service design, ageing, intergenerational digital community services, participatory design, co-design, design anthropology, responsible AI, inclusive services, and community-based wellbeing.

## How this repository should be used

Use this repository as a stable context and template base when working with ChatGPT, Codex, or other AI research assistants.

The repository should help the assistant avoid generic summaries and instead connect every paper, supervisor profile, and writing task to the user's PhD application strategy.

## Core principle

Do not treat academic papers as isolated summaries. Every reading task should answer:

- How useful is this source for the user's PhD direction?
- What research problem, theory, method, or gap can be extracted?
- Can this source support a proposal, literature review, supervisor email, personal statement, or research identity?
- What should be used cautiously or avoided?

## Main workflows

### 1. Paper reading

Use `templates/paper_reading_template.md` to analyse academic papers. The output should include usefulness judgment, research problem, theoretical framework, methodology, findings, limitations, relevance to the user's PhD direction, and possible use in application writing.

### 2. Supervisor matching

Use `templates/supervisor_profile_template.md` to analyse potential PhD supervisors. The output should evaluate thematic fit, methodological fit, supervision possibility, institutional context, natural connection with the user's background, email angle, and risks.

### 3. Literature review development

Use `templates/literature_review_matrix.md` to turn individual paper notes into thematic literature review sections. Avoid listing papers one by one; organise them around research problems, concepts, methods, and gaps.

### 4. Research proposal writing

Use `templates/research_proposal_template.md` to develop proposal drafts. The proposal should remain academically grounded but open enough for PhD application.

### 5. Motivation letter and supervisor email writing

Use `templates/motivation_letter_template.md` and `templates/writing_style_guide.md`. Writing should be sincere, specific, precise, exploratory, and not exaggerated.

## Suggested prompt

When using ChatGPT with this repository, use prompts such as:

> Use my academic research skill codex to read this paper. Do not only summarise it. Judge whether it is useful for my PhD direction and explain how it can support my research proposal, literature review, or supervisor communication.

or:

> Use this repository's supervisor profile template to analyse this potential PhD supervisor. Focus on research fit, method fit, PhD supervision possibility, best email angle, and risks.
