# Literature Notes

Store structured paper reading notes here.

Recommended file naming format:

```text
YYYY_author_short-title.md
```

Example:

```text
2024_pink_design-anthropology-community-services.md
```

Each note should be produced using `templates/paper_reading_template.md` and may later be reorganised through `templates/literature_review_matrix.md`.

Suggested subfolders:

- `ageing_and_intergenerational_care/`
- `co_design_and_participatory_methods/`
- `design_anthropology/`
- `responsible_ai_in_community/`
- `service_design_and_community_wellbeing/`
