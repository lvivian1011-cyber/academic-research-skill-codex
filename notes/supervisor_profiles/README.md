# Supervisor Profiles

Store structured supervisor analyses here.

Recommended file naming format:

```text
institution_supervisor-name.md
```

Example:

```text
monash_sarah-pink.md
uts_olivia-rawlings-way.md
```

Each profile should be produced using `templates/supervisor_profile_template.md`.

A strong supervisor profile should include:

- research themes;
- key publications or projects;
- methodological orientation;
- PhD supervision possibility;
- fit with the user's research identity;
- best email angle;
- risks or mismatch;
- final fit score.
