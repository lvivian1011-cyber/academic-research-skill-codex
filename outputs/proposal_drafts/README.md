# Proposal Drafts

Store research proposal drafts here.

Recommended file naming format:

```text
YYYY-MM-DD_proposal-version-topic.md
```

Example:

```text
2026-09-04_v1_intergenerational-digital-community-services.md
```

Proposal drafts should use `templates/research_proposal_template.md` and should remain exploratory enough for PhD application.

Each proposal draft should clearly show:

- research background;
- research gap;
- aim;
- research questions;
- theoretical framework;
- methodology;
- expected contribution;
- supervisor fit;
- scope risks.
