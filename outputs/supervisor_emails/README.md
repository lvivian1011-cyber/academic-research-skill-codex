# Supervisor Emails

Store tailored PhD inquiry emails and motivation-letter variants here.

Recommended file naming format:

```text
YYYY-MM-DD_institution_supervisor-name_email.md
```

Example:

```text
2026-09-04_uts_olivia-rawlings-way_email.md
```

Each email should use `templates/motivation_letter_template.md` and `templates/writing_style_guide.md`.

A strong supervisor email should include:

- brief self-introduction;
- emerging PhD interest;
- specific connection to the supervisor's work;
- cautious and open framing;
- polite request for possible discussion or advice.
