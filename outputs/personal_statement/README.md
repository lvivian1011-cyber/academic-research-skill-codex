# Personal Statement

Store personal statement drafts and application narrative versions here.

Recommended file naming format:

```text
YYYY-MM-DD_personal-statement-version.md
```

Example:

```text
2026-09-04_personal-statement-v1.md
```

Personal statement writing should connect:

- Industrial Design teaching background;
- interdisciplinary design education;
- design psychology and ergonomics;
- smart product and service design experience;
- community-oriented design interest;
- emerging PhD direction in ageing, intergenerational communities, participatory design, and responsible technology.

Avoid exaggeration and avoid presenting the PhD topic as already fixed.
