# PhD Relevance Matrix

Use this matrix to judge whether a paper is strategically useful for the project **PhD Application 2026 – Design, Ageing & Community**.

The purpose is to avoid collecting literature randomly. Each paper should be evaluated according to how it supports the user's PhD direction, supervisor matching, research proposal, and application writing.

## 1. Relevance dimensions

Score each dimension from 0 to 5.

| Score | Meaning |
|---:|---|
| 0 | Not relevant |
| 1 | Very weak relevance |
| 2 | Indirect relevance |
| 3 | Moderate relevance |
| 4 | Strong relevance |
| 5 | Core relevance |

## 3. Overall classification

After scoring, classify the paper as one of the following.

### Core paper

Use when the paper strongly supports at least three of the following:

- ageing or older adults
- intergenerational practice
- community wellbeing
- participatory / co-design method
- service design or design anthropology
- digital or AI-mediated community service
- directly relevant supervisor / institution

### Supporting paper

Use when the paper is not central to the topic but provides a strong method, theory, case, vocabulary, or argument.

### Background paper

Use when the paper helps explain context but is not central to the proposal.

### Low-priority paper

Use when the paper is only loosely related and unlikely to appear in proposal, PS, or supervisor emails.

## 4. Strategic use checklist

For each paper, check all that apply.

- [ ] Can support research background.
- [ ] Can support literature review.
- [ ] Can justify research gap.
- [ ] Can inform research questions.
- [ ] Can support methodology.
- [ ] Can support theoretical framework.
- [ ] Can support expected contribution.
- [ ] Can be mentioned in a supervisor email.
- [ ] Can be used in a personal statement.
- [ ] Can help compare supervisors or institutions.

Use this short paragraph after every reading note.
