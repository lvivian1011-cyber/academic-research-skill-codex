# Literature Clusters

Use this file to organize literature by theme rather than by author only.

# Cluster 1｜Ageing & Community

## Core question

How do older adults experience, access, and participate in community life, and how can design support age-friendly environments and services?

## Possible subthemes

- Age-friendly communities
- Ageing in place
- Community care
- Social participation
- Loneliness and social isolation
- Everyday mobility and accessibility
- Community wellbeing

## Key papers

| Paper | Main contribution | How I can use it |
|---|---|---|
|  |  |  |

## Possible proposal argument

> Ageing should not be understood only as an individual health or care issue, but as a situated community experience shaped by service systems, social infrastructure, everyday participation, and intergenerational relationships.

## Possible subthemes

- Participatory design
- Co-design workshops
- Stakeholder engagement
- Community-based design
- Design probes
- Participatory prototyping
- Power relations in co-design
- Ethical participation

## Key papers

| Paper | Main contribution | How I can use it |
|---|---|---|
|  |  |  |

## Possible proposal argument

> A participatory and co-design approach is necessary because intergenerational community services involve multiple stakeholders whose needs, values, and forms of participation cannot be predefined by designers alone.

## Possible subthemes

- Responsible AI
- AI ethics
- Algorithmic care and risk
- Human-AI collaboration
- Social acceptability
- Trust and transparency
- Inclusive AI
- Data justice

## Key papers

| Paper | Main contribution | How I can use it |
|---|---|---|
|  |  |  |
